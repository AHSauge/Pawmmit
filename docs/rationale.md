Rationale behind Pawmmit
==================================
This is a fork of Gittyup, and is first and foremost a means to provide myself (@AHSauge) a git client with latest fixes and with more advanced features. As it's part of my professional, full-time development workflow, I find it important that it stays secure with relevant patches. If others find the contributions useful, I'm open to collaborating on this further.

Generally speaking, the focus is on providing performance, security, and usability improvements, in addition to commercial grade features. Some efforts are made to simplify the GUI and improve the usability.

Whilst I will continue to contribute to Gittyup, there are some concrete differences that either already exist or may appear in the future.

1. Branding. This is re-branded to ensure a clear separation from Gittyup and GitAhead, and avoid any confusion on that matter.
2. The codebase is GPLv3 instead of MIT. This provides a stronger assurance that the code, including improvements, stays open-source, which allows contributors concerned with the relaxed aspects of an MIT license to contribute without that concern. Contributors are of course allowed to upstream their own fixes to Gittyup, and for existing contributions, there's always the option to ask the author for approval to upstream it under MIT license.
3. I (@AHSauge) use this as a technical test-bed for meson. For example, this highlights some friction using Qt in meson, and I'm likely to use this to improve meson
4. GUI changes that are not acceptable upstream
